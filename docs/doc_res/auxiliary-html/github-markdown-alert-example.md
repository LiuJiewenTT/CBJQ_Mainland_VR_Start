# Example of GitHub Markdown Alerts

## By GitHub

> Plain
> 
> This is a plain blockquote.

> [!NOTE]
> 
> This is a note.

> [!TIP]
> 
> This is a tip.

> [!WARNING]
> 
> This is a warning.

> [!CAUTION]
> 
> This is a caution.

> [!IMPORTANT]
> 
> This is an important note.
